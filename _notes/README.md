# 🗒️ Raw Notes (private scratch)

Personal, unpolished note-taking space. **Committed to git** (so it's backed up and synced across
machines) but **excluded from the published site** via `exclude_docs: _notes/` in `mkdocs.yml`.

## How to use

- Drop raw `.md` files here — ideas, rough drafts, problem write-ups, things to add later.
- Nothing in this folder appears on the MkDocs site, so formatting/quality doesn't matter.
- When a note is ready, **propagate** it into the real content (DSA, SystemDesign, Fundamentals,
  QA-Bank, Databases, Behavioral, InterviewPrep) and delete or trim it here.

## Notes

- This folder is **not** in `.gitignore` — it IS committed. If you ever want a note to stay purely
  local (never pushed), add that specific file to `.gitignore`.
- Keep the leading `_` — it marks the folder as private/scratch and sorts it out of the way.
